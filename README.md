# quickhr 🤖🙋‍♀️
quickhr : | HR Agent | Amazon Quick Suite, Custom Chat Agent, Spaces, Builder, Persona |


## Objectives
- Create Amazon Quick spaces & upload documents it.
- Test document retrieval with sample chat prompts.
- Create custom chat agents using Quick Agent Builder.
- Configure Quick agent persona, communication style & knowledge sources.
- Shared custom chat agent with another Quick user.
- Test agent & refine agent configuration based on test results.
- Documented how to maintain & share custom chat agent.
